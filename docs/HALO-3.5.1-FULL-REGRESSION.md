# HaloTV 3.5.1 全量回归测试版

这是基于第二阶段 Issues 测试版的本地构建，不是正式发布。可见版本 3.5.1，Standard/Guard 内部版本 274，Lite 121。

## 已确认并清理

- 最高刷新率设置此前已经没有界面入口，启动时仅将窗口刷新率偏好设为系统默认。现移除整条无效链路：设置枚举、旧 SharedPreferences 读写、窗口模式选择辅助类、从活动到壁纸设置的无调用回调、旧调试开关、五语种旧选项和失实文档。旧偏好值不会再被读取，也不主动擦除用户其他配置。
- 保留真实显示模式/实际刷新率诊断、帧率统计、4K 画布兼容逻辑。保留本地和航拍壁纸播放器的禁止帧率切换策略，不改独立屏保播放策略。
- 删除两个无运行时调用、无工具依赖的 `.kt.orig` 补丁备份；不删除对应活动源码。
- 清除遗留未调用的四个私有设置组件（旧分组标题、打赏码布局、天气值、手机二维码卡片）及一个未使用的网格常量。新设置、天气、手机管理、打赏和真实网格渲染仍走现有实现；没有批量删除 Lint 疑似未使用资源。

## 校验边界

桌面包的签名、内部码、包名、构建、单测、Lint 和实际覆盖升级条件以同行验证报告为准。主机/模拟器互不替代真电视，具体固件的冷开机、守护、解码、遥控器和显示输出仍需实机。未发布、未修改更新源、未安装到实体电视。

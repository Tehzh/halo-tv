# Halo TV 3.0 单页欢迎测试版

## 本次变更

- Guard、Standard、Lite 共用单页原生欢迎页，按用户选择的第一版效果还原。
- 替换旧七页引导，删除已不使用的三张引导截图；作者头像仍供联系作者页面使用。
- 全新安装、旧版升级后首次打开会显示欢迎页。用户选择「开始使用」后写入独立完成标记，之后重开或同安装升级不再重复出现。
- 欢迎页不创建视频播放器、不运行定时动画；退出后释放背景位图。背景 JPEG 约 100 KB。
- 移除电视端正式版在线视频/必应壁纸以及 Lite 必应壁纸的「下载到本地」选项。
- 手机在线图库只提供预览与设置为壁纸。旧手机页面发送 download=true 也只走可替换缓存，不会加入用户本地照片。
- 用户自行上传的本地照片/视频及既有素材不删除、不迁移。
- 在线视频仍通过播放网络地址使用；必应壁纸保留当前显示所需的可替换私有缓存。因此移除「保存到本地」不意味着完全不占磁盘缓存。

## 版本

可见版本均为 3.0；Guard/Standard 内部号 173，Lite 内部号 30。包名与签名延续旧版。

## 检查范围

Release 编译、Android API 兼容检查、欢迎页完成/旧引导迁移/遥控按键防误触单测；隔离 Android 电视模拟环境验证欢迎页及再次打开。未安装用户电视，未公开发布。

## 美术素材

背景使用内置图像生成工具，按第一版参考图保留午夜蓝光晕、地平线与顶部 Halo TV 品牌图形，移除其余文字和按钮。所有欢迎文字、按钮及遥控交互由原生 View 绘制，并由正式版与 Lite 共用。

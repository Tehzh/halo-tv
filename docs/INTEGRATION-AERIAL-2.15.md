# HaloTV 3.5.1 上游整合测试版

本批仅用于验证上游整合，后续的 HaloTV Issues 修复以本批提交为起点。

- HaloTV 基线为 3.5 正式版提交 `0ce202adf0ad62535a26ea375f89e55995bdebb4`。逐文件比对桌面正式版源码压缩包，全部 730 个源文件一致。原工作树还有一条本机签名目录链接，正式版源码包已排除它，本批也从版本库索引移除该链接。
- 上次上游整合见 `6c8a59f`（3.3.6）。对比 [Aerial v2.1](https://github.com/pengchujin/aerial-tv/releases/tag/v2.1) `50056e3f8de6a13f111db06df5a0f59eebba0f76` 到 [Aerial v2.15](https://github.com/pengchujin/aerial-tv/releases/tag/v2.15) `c9a84b11e5ed1f19b5ad026eae6bc7d75d13feb7`。桌面 2.15 ZIP 和 TAR.GZ 各 412 个文件，逐文件一致。上游 Standard 2.15 和 Guard 2.15-guard 内部号 157，上游 Lite 实际为 1.38、内部号 40。
- 本批三个 HaloTV 包显示 3.5.1，Standard / Guard 为 272，Lite 为 119，仍使用 HaloTV 独立版的应用 ID、发布证书和构建方式。APK 核验记录随本批交付。Standard / Guard 最低 Android 5.0，Lite 最低 Android 4.0。

## 合入与冲突处理

| 上游改动 | 本批处理 |
| --- | --- |
| 2.15 手机图标库布局、搜索和跨应用选择 | 三版共用网页及既有图标源，按名称、别名和包名搜索。保留 HaloTV 的受限模式 PIN、已有图标缓存修复和手机接口。选择时先验证并取到图片，再变更选项。来源包名和图片 ID 一起区分借用图与同名 ID，保留原图标设置格式。 |
| 极米锁定开机和唤醒出现桌面选择框 | Standard / Guard 仅以真实 Activity 的窗口事件判定是否已有画面，并在开机/唤醒后限时检查前台选择框。返回动作成功后停止当次检查。保留 HaloTV 原有的守护授权、解绑及更新恢复。 |
| 创维酷开长辈桌面 | Standard / Guard 识别厂商模式桌面及已知长辈桌面 Activity；按现有桌面接管规则处理。 |
| 诊断 | Standard / Guard 守护和通知服务输出当前状态。已有诊断文件开关打开时，保留解锁前的内存记录；诊断继续包含 HaloTV 的网络校验状态。 |
| 峰米 FengOS 亮度、旧 TCL 图像设置 | 三版对检测到的 FengOS 避免读写亮度，TCL 图像设置服务使用遥控器设置键的参数。保留 HaloTV 已有的亮度失败回退。 |
| 暴风 AML_T962 | 三版在「全部应用」中发现可打开的厂商直播、信号源入口。 |
| 每日壁纸日期 | 三版记录图库的 UTC 上线时间，保留 HaloTV 已选每日壁纸和原缓存更新流程。上传长图的尺寸限制在 3.5 已有，继续使用各版本限制。 |
| TalkBack 和照片屏保 | Standard / Guard 填充按钮、磁贴与 PIN 删除键的读屏语义，遵守原遥控焦点及弹层交互门控；照片屏保时钟采用上游的等比例字距过渡，原屏保模式与失败回退保留。 |

## 保留 HaloTV 3.5 的部分

- 上游把关于、更新和状态移出控制中心，本批保留 HaloTV 的入口和排版。上游新增电池状态和手机关机、到期自动待机、微鲸电源指示灯写入均留在本轮范围之外。
- 上游天气过期提示及调度未合入。HaloTV 的可切换天气源、位置变更请求代次、失败回退和前台定时检查继续用原逻辑。
- Aerial 官网及发布配置、诊断上传去向、Aerial 安装及还原脚本、上游版本号和应用标识不导入。图标目录、下载和许可沿用各自既有来源。保留 HaloTV 的公告、更新、受限模式、Dock、灵动岛、启动图和 Lite 构建差异。
- 本批未安装到电视，未推送源码，未发布。极米开机/唤醒、创维长辈桌面、峰米待机恢复、老 TCL 和暴风入口、Safari 实机及 Android 4.x 解码器等依赖真实设备的行为仍待验证。

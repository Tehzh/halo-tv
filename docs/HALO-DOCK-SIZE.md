# Dock 与图标大小

本地对齐修复测试包：版本显示 3.3.4；Standard / Guard 内部号 248，Lite 104。

- 设置 → 应用与 Dock → Dock 与图标大小：小（90%）、默认（100%）、大（110%）。
- Dock 底板、应用图标、横向间隔和底板内边距联动调整，保持居中。保留现有圆角、底板、名称和每排应用数量选择。
- 未设置过此选项的安装使用默认尺寸，不修改旧设置。切换后即时生效，重启保留选择。正式版恢复应用与 Dock 的默认设置时也恢复默认尺寸。
- 手机设置页「桌面外观」同步提供三档选择；接口拒绝非法档位。三版本使用同一份尺寸计算，Lite 继续兼容 API 14，不新增依赖。
- 焦点位置、图标缓存尺寸、名称位置和滚动距离随图标更新。左上、右上时间信息跟随图标行左右边缘；顶部设置与状态栏信息跟随对应 Dock 边距，保留默认档的原有位置。文字大小和其他设置页面不随 Dock 缩放。
- 正式版保留已有的高分辨率图标素材，只异步重建必要尺寸的图标表面，不因切换大小重新扫描应用或加载图标库。
- 大尺寸优先保证遥控器焦点与双排末行在可视范围内，沿用双排抬升和时钟避让逻辑。无持续缩放动画、定时器或空闲任务。
- 对齐修复覆盖正式版的左上/右上时钟、状态栏和顶部设置入口，以及 Lite 的时钟和状态入口。居中时钟继续保持居中；不需要重启或重建桌面。

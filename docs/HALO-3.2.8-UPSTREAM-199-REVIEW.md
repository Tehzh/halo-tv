- 桌面、Dock 和焦点：审查图形缓存、位图准备与绘制路径；保留已有按需合成、后台准备焦点图、受控并发和缩小缓存方案，未更换视觉样式。
- 控制中心、设置、系统应用入口：审查面板生命周期、系统查询、焦点滚动与系统入口兜底；系统 Settings 递归启动的既有修复保留，并由已有回归用例覆盖。
- 视频、屏保、外部应用返回：审查播放器停止/释放、遮罩回调、画面复制和协程生命周期；保留上一轮单解码器交接、首帧淡出、相同本地视频复用和返回不重复等空闲计时的方案。
- 守护、默认桌面和权限：复审新包名组件、恢复上限、延迟回调和关机路径；没有把系统权限伪装成普通安装即可自动全部获取，也不覆盖其他应用的无障碍/通知授权。
- 手机服务、上传及更新：复查后台服务中的阻塞调用位置、文件校验/上传路径和更新安装会话；保留独立包名/签名校验、安装确认与现有回归，不放宽安装其他 APK。
- 儿童答题、家长 PIN、公告：保留原生焦点隔离和公告完成逻辑，运行既有相关测试；没有重新设计儿童界面。
- Lite 生命周期与资源：重点复查绘制、时钟查询、缩略图与关闭页面后的工作；保留之前把内存/存储读取移出绘制的修复。
- 检查 Lint 的绘制分配及静态引用告警：许多引用是 Application Context 或在退出时清除的活动服务/覆盖层，未把所有警告都认定为实际泄漏，也没有通过批量 suppress 隐藏问题。未对每个依赖的内部实现作人工逐行审计。

## 验证边界与实机观察项

这是源码审查、主机单元/UI 回归、Lint 和 APK 验证，不是电视帧率/PSS实测。不承诺每台电视零卡顿、零闪屏或全部特殊权限可开启。仍需分别测试静态/本地视频/在线视频壁纸、连续图标移动、控制中心开合、不同屏保和外部应用返回；守护需实测冷开机、待机唤醒、取消关机和重启。外接音响、TCL MS901、乐视、飞利浦及创维海思适配未在本轮对应实机验证。

天气的 HTTP 兼容回退不加密；仅沿用上游指定天气服务的兼容策略。初始视频缓冲更短在慢网络下可能较早触发再缓冲。小过渡图不改变实际视频播放分辨率；照片/时钟屏保保留一个暂停解码器，属于连续性与资源占用的折中。

# HaloTV 3.0.1：整合 Aerial 1.94

日期：2026-11-11。工作分支：`halo-301-upstream194`。

这是基于 HaloTV 3.0 兼容修复代码的三方合并，保留 HaloTV 定制功能；不是用原版 APK 改名字。对应上游为用户提供的 Aerial 1.94 源码和该版本的三个 APK。本轮仅生成本地安装包，没有安装电视、发布仓库或修改官网更新清单。

## 来源与版本

- Halo 基线：`76bb343`，包含 3.0 发布后的媒体、天气、声音、缩略图、守护、安装兼容修复。
- 合并祖先：本地 Aerial 1.89 源码快照 `efafe26`。
- 上游：`pengchujin/aerial-tv`，桌面 `aerial-tv-1.94.zip`。ZIP 与同名 tar.gz 解压后的 400 个文件内容一致。
- ZIP SHA-256：`9e69016357457e7e58385e874b261242c6a7ba79b59774844b6eac178127b1ac`。
- 1.94 对应原版正式 APK 内部号 133；同批 Lite 显示版本 1.28、内部号 30。Lite 不以文件名猜测其版本。
- HaloTV Guard / Standard：显示版本 **3.0.1**，内部号 **178**，最低 Android 5.0 / API 21。
- HaloTV Lite：显示版本 **3.0.1**，内部号 **36**，最低 Android 4.0 / API 14。
- 包名与签名保持现有升级关系；Standard 声明系统 HOME，Guard 继续不声明 HOME，Lite 保持独立包名。相同包名、相同签名且内部号较低的安装包可进行覆盖升级；这不意味着三个版本可以互相覆盖。

## 合入的主要上游改进

### 遥控器、守护与开机

- 修正 vendor/product 为 1/1 的部分内置遥控器被判断成游戏手柄，导致按键过滤策略错误的问题。
- 用同次开机的内核 boot ID 辅助判断桌面离开记录，减少电视联网校时后把本次开机误判为另一次开机。
- 守护重绑时识别已恢复的 HaloTV，减少重复拉起和焦点跳回首个应用。
- 对已在前台运行的应用增加保护与退出观察，避免守护恢复后反复盖住正在观看的应用。
- 合入 LeTV 无窗口事件时的恢复修正、XGIMI 部分锁定启动黑屏的恢复分支。
- Home 长按时保持过滤至按键抬起，减少 TCL 最近任务界面被抬键事件意外关闭的问题；修正部分 Coocaa 默认桌面情况下过滤配置不生效。
- 合入 FengOS 网络/设置入口、Skyworth 信号源广播和 Baofeng 信号源回退入口。

厂商权限、开机策略、无障碍被系统清理仍受固件控制。本地测试不能保证所有电视零闪原桌面或隔日守护始终有效。

### 动态壁纸、图片与画面交接

- 保留 Halo 的播放器画面代次校验、取消安全与首帧交接；适配上游的本地视频离开时画面捕获，捕获预算维持 350 ms，慢任务不阻塞返回桌面的播放器启动。
- 合入画面复制异常恢复标记：在相同固件上若上次进程在画面复制期间终止，后续避免反复走这条路径，优先回退到可用的静态帧/软件画面方案。该标记是保守恢复策略，不能据此证明每次终止都由驱动崩溃造成。
- 媒体文件读取反复拒绝后停止反复尝试；Android 6–8 的 MP4 解析器识别改用正确的系统库位置。
- 画面尺寸取实际窗口方向，主界面、配置变化和系统屏保入口更新图片尺寸；照片屏保及毛玻璃缩略图兼顾横竖方向，避免强行横屏比例导致拉伸。
- 保留在线壁纸使用 TextureView 填满窗口的兼容修复，不恢复先前小块显示的路径。
- 保留图片毛玻璃原图所有权、滚动累加模糊算法、极端宽高图像解码预算等 Halo 优化。

没有恢复用户已删除的实验性强制 4K 画布选项；界面布局仍按既有逻辑画布自适应，不按电视物理尺寸重排布局。

### 图标库与手机管理

- 支持新版图标库索引：同一应用可有多个图标选项，显示各自来源；同时兼容旧版单图索引。
- 手机端更换图标后直接读取保存的选择，避免将旧图标缓存为新选择。
- 系统快捷入口的生成图标保留原行为，仅在用户明确选择图标库时替换；用户自行上传的图标继续优先。
- 新版安装后重新检查索引，清理不再适用的库文件，保留已选择的图标设置。
- 补充索引缓存损坏/不可读保护，避免启动崩溃或延迟 12 小时才重新请求。
- Lite 手机缩略图响应使用完即释放本次解码图，保留桌面共享图标，降低重复请求时的临时图片内存。

### Lite 恢复重试

- 保留独立的联网工作队列，不让天气/在线图标刷新堵住本地图标与壁纸加载。
- 每日壁纸首次获取失败后，网络恢复时重试，并提供半小时的失败重试；天气也可在网络恢复后重新请求。
- 保留活动销毁与旧回调保护、24 小时内已获取天气的容错显示。
- Lite 继续使用原生 View，不加入正式版 Compose、在线视频壁纸或液态玻璃依赖。

## 保留的 Halo 功能与既有修复

保留控制中心、新设置分类、儿童答题和长辈模式、农历/时间显示、两种 Dock 圆角、文字颜色、在线静态壁纸、正式版在线视频、本地素材、手机管理、限定 Halo APK 的手机推送、官网优先更新及自动下载设置。没有将更新源换回原版 Aerial。

前一轮兼容修复继续保留：按键声音关闭与静音透传、天气 TLS/重试和缓存、缩略图并发/尺寸限制、屏保类型与本地播放器不串用、Standard HOME 类别组合匹配、守护自身组件恢复并保留其他无障碍服务、小米亮度失败后的真实回退、标签“秒钟显示”、v1/v2 签名。

## 有意未直接移入的内容

- 上游 `SelfCompile` 的后台自行重装流程：Halo 先前已移除该流程。本次不恢复，以免与现有更新安装状态和守护生命周期重复。已有基线配置、正常安装后的系统编译仍保留；不宣称获得这条自重装路径带来的性能收益。
- 上游官网、下载清单、图标投稿工具及发布文案：不覆盖 Halo 官网或公开版本，不引入原版更新入口。相关源码运行时接口有变化的部分已单独适配。
- 不自动授予新权限、修改默认桌面、清理用户数据、安装其他应用或改变系统网络。

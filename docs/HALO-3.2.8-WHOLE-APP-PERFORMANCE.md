# HaloTV 3.2.8 性能复审测试（内部号 231 / 87）

本次是本地测试包，未发布、未操作电视或模拟器。保留独立版包名、签名、启动图和现有视觉样式。

## 已处理

- 控制中心额外的强制离屏缓冲改为按需合成；隐藏时不测量整张面板，离开桌面/进入屏保时释放面板组合，回到桌面空闲后预热。
- 收紧上一轮扩大的公共图形缓存：完整版 40→8 MiB，低效果模式 12→4 MiB，Lite 8→4 MiB。上限仅针对该缓存，不代表整个进程内存下降同等大小。玻璃边缘直接保留在绘制节点，避免每帧缓存查询及逐出后的重复生成。
- 焦点图标放大图像改成后台准备；准备期间使用原图，绘制帧内不再临时生成焦点位图；批量图标准备并发从 5 降至 2，减少与动画争用 CPU。
- 焦点滑动位移在布局阶段读取动画值；空闲清理监听移至独立协程，减少每次遥控输入引发桌面重组。
- 返回桌面的包变化检查移至后台，非紧急系统/内容查询延后 600 ms；应用安装广播合并，信号源短期复用且手动打开仍可刷新；网络状态读取移至后台并合并连续通知。
- 普通应用启动复用应用扫描所得的设置/桌面身份，避免每次确认都遍历系统解析器；保留未知应用探测及家长密码检查。
- 在线视频离开桌面时避免同步 TextureView 大图读取；停止后的截图延后到面板动画之后，并限制为 960×540 以内的过渡图（视频播放分辨率不变）。后台补帧及已有返回遮罩仍保留。重复停车幂等化，复用播放器重新准备前仍等待系统信号源释放。
- Lite 时钟绘制不再查询系统内存/存储，改由已有工作线程读取；离开桌面停止分钟刷新。

## 范围与限制

审查重点覆盖桌面绘制、控制中心与设置生命周期、图标加载、播放器/屏保、后台清理、应用启动、守护、更新/手机服务等调用链；没有无依据地重写守护和安装策略。代码检查与主机测试不能证明所有厂商电视绝无卡顿。厂商解码器的停止/释放、系统应用启动和网络响应仍可能阻塞，需要实机对比。没有测得本轮真实 PSS、帧率或掉帧改善，不作百分比承诺。

过渡截图更小可能在短暂停留时较软；正常静态壁纸及视频播放画质不变。首次控制中心打开仍可能产生必要的纹理上传。更小缓存会增加少量首次绘制工作，需与上一测试包比较。

## 建议用户对比

同一壁纸及性能模式下：冷启动/热返回、左右连续选图标、控制中心开关、设置进出、外部视频应用返回；再分别观察静态/本地视频/在线动态壁纸。测试包不自动安装到电视。

## 本轮验证结果

- 三个 Release 构建成功；Standard 488、Guard 488、Lite 154 项测试，失败/错误/跳过均为 0。另有 27 项独立守护脚本测试通过（本机桩测试，未连接电视）。
- Lint 无 Error/Fatal；Standard 333、Guard 334、Lite 418 项 Warning，未宣称消除全部历史兼容/弃用警告。
- 三个 APK 的 apksigner、zipalign、包名、版本号、内部号核验通过；签名继续为独立版 ed28a197…c41dd。
- 没有模拟器、电视实测或公开发布。
